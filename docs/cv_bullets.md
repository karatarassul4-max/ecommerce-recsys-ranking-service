# CV Bullet Points

- Built a production-style implicit-feedback recommendation service on RetailRocket e-commerce events, covering preprocessing, temporal validation, offline ranking metrics, model artifacts, and FastAPI serving.
- Implemented and compared popularity, item-kNN collaborative filtering, SVD candidate generation, and a lightweight two-stage ranking model with Recall@K, Precision@K, NDCG@K, MAP@K, and coverage evaluation.
- Designed leakage-safe train/validation/test splitting and cold-start fallback behavior for realistic recommender-system evaluation.
- Added Docker, pytest, GitHub Actions CI, structured configuration, logging, and MLflow experiment tracking for reproducible local runs.
